# ROAM Swipe

**Turn reference carousels and reels into on-brand remixes, then review them like a team.**

A local-first remix pipeline plus a review dashboard: decks in, branded drafts out, approve or request changes on a board.

## What it does
- **Generate:** remix a source deck into your brand's look and voice
- **Review:** kanban board and gallery with status per deck
- **Render:** export finished carousels and reels
- **Two modes, one codebase:** local filesystem engine or hosted review (`ROAM_STORE`)

Setup and architecture: [SETUP.md](SETUP.md)

**Stack:** Next.js · React · Tailwind
